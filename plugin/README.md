# Reader's Ear

A Claude Code plugin with one skill, `readers-ear`. The skill has the agent revise prose, in any language and genre, until it reads naturally to its intended reader.

Install it in a Claude Code session (Claude Code 2.1.275 or later):

```
/plugin install readers-ear --marketplace motestream/readers-ear
```

The skill writes outside the conversation only when you choose or change its scope, that is, whether it revises everything the agent writes or only text for other people. It then saves one sentence to your personal instructions or account memory and tells you where.

For what the skill does, how to install it, and translations into seven languages, see the [main README](https://github.com/motestream/readers-ear#readme). Released under the MIT License.
